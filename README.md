# Enterprise-FortiGate-Network-Security-Lab

This project builds a realistic Enterprise FortiGate network and security environment using FortiGate and EVE-NG. The lab simulates common company requirements such as secure Internet access, network segmentation, DMZ services, firewall policies, NAT, VPN connectivity, secure administration, monitoring, SD-WAN, and security controls.

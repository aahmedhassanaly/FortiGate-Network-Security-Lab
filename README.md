# Enterprise-FortiGate-Network-Security-Lab

This project builds a realistic enterprise network security environment using FortiGate and EVE-NG. It covers network segmentation, secure Internet access, firewall policies, NAT, DMZ publishing, VPNs, security inspection, monitoring, and SD-WAN failover.
